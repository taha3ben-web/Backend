# ADR-0004: إصدار الـ API عبر المسار مع التوافق الخلفي

- **الحالة:** مقبول (Accepted)
- **التاريخ:** 2026-07-17

## السياق

تطبيقات الموبايل (راكب/سائق) تحتاج مسارات مستقرّة قابلة للتطور، دون كسر الإصدارات
المنشورة من التطبيق.

## القرار

إصدار عبر المسار (URI Versioning) ببادئة `v`، مع جعل الإصدار الافتراضي
يشمل `"1"` و`VERSION_NEUTRAL` معًا.

- المسارات القديمة (بلا إصدار) تبقى تعمل: `GET /api/health`.
- ونفسها متاحة تحت v1: `GET /api/v1/health`.
- البادئة العامّة `/api` موحّدة.

## البدائل المرفوضة

- إصدار عبر الترويسة (Header): أقل وضوحًا في السجلّات وأصعب للاختبار اليدوي.
- كسر المسارات غير المُصدّرة فورًا: يكسر العملاء المنشورين.

## التبعات

- أي تغيير كاسر مستقبلي يدخل تحت `v2`، مع إبقاء v1 فترة انتقال.

## المراجع

`src/main.ts` (`setGlobalPrefix("api")`، `enableVersioning`).
